GUÍA PARA REEMPLAZAR LAS FOTOGRAFÍAS - JARDINERÍA EL AMANECER
====================================================================

Hola Salvador y familia. En esta carpeta puedes colocar las fotos reales
de tus trabajos de jardinería.

Para que se actualicen automáticamente en la página web, solo debes guardar
tus fotos con los siguientes nombres:

1. IMAGEN PRINCIPAL (Encabezado):
   - hero-jardin.jpg (Foto amplia y llamativa de un jardín)

2. TARJETAS DE SERVICIOS:
   - servicio-jardines.jpg      -> Para el servicio de Jardines
   - servicio-limpieza.jpg      -> Para Limpieza de terrenos
   - servicio-fumigacion.jpg    -> Para Fumigación
   - servicio-fertilizacion.jpg -> Para Fertilización

3. GALERÍA DE TRABAJOS:
   - trabajo-1.jpg
   - trabajo-2.jpg
   - trabajo-3.jpg
   - trabajo-4.jpg
   - trabajo-5.jpg
   - trabajo-6.jpg

4. SECCIÓN SOBRE NOSOTROS:
   - sobre-nosotros.jpg (Foto trabajando, herramientas o jardín familiar)

CONSEJOS:
- Recomendamos que las imágenes estén en formato .jpg o .png.
- Para que la página cargue rápido, procura que las fotos no pesen más de 2MB cada una.
- Si agregas más trabajos, simplemente puedes duplicar los bloques en el archivo index.html.
